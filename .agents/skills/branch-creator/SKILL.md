# Skill: branch-creator (Redirect)

Cette compétence est désormais obsolète. Pour toute opération de création de branche, de nommage ou de gestion du cycle de vie Git, veuillez utiliser la skill **`git-governance`**.

L'utilisation de `git-governance` garantit le respect du standard unique : `<SKOTCKER>-<feature>(<nomgithub>)`.
