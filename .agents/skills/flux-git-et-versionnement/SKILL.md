# Skill: flux-git-et-versionnement (Redirect)

Cette compétence est désormais obsolète. Pour toute opération de versionnement, de formatage de commits ou de stratégie de push, veuillez utiliser la skill **`git-governance`**.

L'utilisation de `git-governance` garantit la cohérence de l'historique et le respect du format strict : `<type>(<périmètre>): [Groupe X] <description> (#<issue>)`.
